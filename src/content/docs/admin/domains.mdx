## Purpose
Admins register or connect domains, move them to Cloudflare and apply DNS templates for cold sending or brand mail. Route: `/domains`; backed by `services/domains`.

## What works with the real API
- Registrar (Dynadot) status and domain search (`/registrar/search`) through the domains service.
- Lists and requests domains, approves a price, registers, sets nameservers and checks the Cloudflare zone.
- Previews and applies DNS changes, and runs a health check.
- Paid steps need an explicit approval first.

## Not finished yet
- In demo mode the page runs a local engine and is labelled MOCK.
- DNS templates in the page use placeholder DKIM keys; real keys are not generated by the UI.
- Real-money registration depends on a configured registrar key; its live state is not verified.
