## Purpose
HeroCloud is a web CRM. A sales team finds leads, calls them, sends offers, gets contracts signed and takes payments. Backoffice then buys and stores the gold and confirms to the customer. Everything lives in one app. Different roles see different pages: see [Roles](/start/roles/).

The app has two modes. **Demo mode** uses fake data kept in your browser. **Live mode** talks to the real backend. Each page below says which parts are real.

## What works with the real API
A typical journey, and the pages involved:

1. A lead arrives and is worked in [Leads](/pipeline/leads/).
2. An agent calls or emails the lead ([Calls](/workspace/calls/), [Inbox](/workspace/inbox/)).
3. The agent creates an [offer](/pipeline/offers/) and the customer signs it.
4. A [payment](/operations/payments/) arrives and is matched to the sale.
5. [Backoffice](/operations/backoffice/) buys the gold; it shows under [Holdings](/operations/holdings/) and in the [customer portal](/operations/customer-portal/).
