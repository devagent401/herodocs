## Purpose
AI attributes lets an admin define fields (for example a score or next best action) that AI computes for contacts. Admins with the AI manage permission use it. Route: `/settings/ai-attributes`.

## What works with the real API
- In live mode definitions are loaded from and registered on the AI service (`/v1/assistant/ai/attributes`).
- Bulk compute runs one real, metered call per contact (`.../attributes/:id/compute`), stopping at the first error such as no credits.
- Results are stored by the server and the new balance is shown.

## Not finished yet
- The field itself is also created in the local metadata store; whether it appears in server-side tables and filters was not verified.
- Automatic recompute on triggers (recomputeOn) is stored but not verified as running on the server.
- The "Try on 5 records" preview always uses the MOCK model: it spends no credits and saves nothing.
- Mock mode uses a fake model, labelled MOCK model.
